## 日志分析扩展位置

下一阶段新增 `ai_test_lab/log_parser.py`，负责“文本行 → 状态列表”；统计逻辑继续留在 `summary.py`，命令行参数和输出由 `__main__.py` 调用。避免把读取、解析、统计和展示全部堆在一起。

样例格式（项目自定义，不代表客户日志协议）：

```text
2026-10-22T10:00:00 INFO case=boot status=PASS
```

解析约定：每个非空行是一条用例执行记录，含一个独立的 `status=PASS` 或 `status=FAIL` 字段；重复 case 按多次执行统计；空白行忽略；非法行报告行号并报错，不静默当作 FAIL。真实日志接入前先明确其格式，再独立增加适配器。

`data/local/` 放本地原始数据，`reports/` 放生成报告，均有忽略规则。公开示例一律使用合成数据。
