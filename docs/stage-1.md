# 第一阶段：7 天 Python 入门与测试结果统计

目标：独立运行、修改并解释一个小程序，为读取日志做准备。每天建议 60–90 分钟；卡住时延长练习，不跳过理解检查。

| 天 | 知识与操作 | 验收 |
| --- | --- | --- |
| 1 | 终端、Python 版本、运行模块、print | 不复制命令也能运行示例，解释终端与 Python 交互窗口的区别 |
| 2 | 字符串、列表、变量 | 新增 FAIL 前预测总数 6、通过 3、失败 3、通过率 50% |
| 3 | for、if/elif、计数 | 用纸笔追踪每次循环的 passed/failed |
| 4 | 函数、参数、return、字典 | 解释为什么统计函数不直接 print，能读取字典中的 total |
| 5 | 空列表、除零、异常 | 解释空输入为何返回 0%，输入 SKIP 为何报错 |
| 6 | import、模块、unittest | 运行全部检查；临时制造计数错误，看到检查失败后恢复 |
| 7 | 综合练习和复盘 | 自己新增失败率显示并验证 0%、40%、100% 三种情况 |

## 动手练习

按顺序完成，每次先写预测再运行：

- 将结果改为全部 PASS、全部 FAIL 和空列表，观察输出。
- 输入 `" pass "`，解释 `strip()` 和 `upper()` 的作用。
- 输入 `"SKIP"`，阅读 traceback，找出抛错的文件和行。
- 在命令行输出中增加失败率：先确定公式，再处理空输入。
- 不看代码，口述“输入 → 循环判断 → 计数 → 返回字典 → 输出”的过程。

第一阶段完成标准：能够解释主要代码、独立修改输入、处理空输入、运行检查并提交一次小改动。下一步才开始文件读取。
